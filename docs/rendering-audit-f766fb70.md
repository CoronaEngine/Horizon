# Horizon 渲染修复与 28 个示例实测

2026-11-14 · Windows x64 · 分支 `new_rhi`

## 审查范围与修复

审查了 `5edc1fee` 引入的 Vulkan indirect raster 后端和 `f766fb70` 引入的 Helicon bindless 路径。性能基线是包含两次提交的 `f766fb70`，修改后是同一检出目录的工作区构建。

- 两个 pass 在第一次提交前录制时，现在能引用同一张隐式深度附件。回归用例同时检验显式深度、隐式深度、颜色加载、深度比较、加法混合和 GPU 生成的 indirect packet，并回读 4×2 像素。
- 入队的 compute dispatch 持有管线及参数快照，执行器按实际完成的 timeline 值释放。测试在入队后、提交前销毁原管线。
- CPU 生成的非零 `firstInstance` 会在不支持时被拒绝。GPU 生成的缓冲区可以用 `IndirectFirstInstance::AlwaysZero` 声明生产者保证。通过覆盖设备能力快照测试了受限路径。
- 修复了 Vulkan 特性结构复制时悬空的 `pNext`、多层及奇数尺寸压缩纹理的初始上传、framebuffer 使用多 mip 或立方体采样视图，以及 multiview 数量的设备上限检查。
- 提交失败不再发布成功状态，录制重试保留原命令和依赖。图形提交链随设备释放。交换链重建重置帧槽，窗口切换重建表面；跨设备复用 staging 前等待上一帧读完。
- 减少管线析构的全设备等待、重复描述符更新、重复读取 buffer device address 和无效 layout 转换。关闭离线 shader 缓存时跳过写生成文件；新缓存键与旧顶点输入布局隔离。

## 采样条件

RTX 2080 渲染并呈现，GTX 1080 同机监控，NVIDIA 驱动 581.80。采用相同的 Conan/CMake 配置、MSVC RelWithDebInfo、ImGui 与 Tracy 开启、离线 shader 缓存关闭。26 个窗口模式保留 swapchain 和 UI 设置，实际交换链为 MAILBOX。baseline、edsl、glsl 为 800×600，其余为 1280×720。

每版每例独立启动 3 次，共 168 次。每个渲染进程在第 17 次 present 后开始计时，共采集 17→18 到 80→81 的 64 个间隔。下表的均值和 P95 各取三轮中位数，P95 取每轮排序后的第 61 个间隔。各示例沿用默认场景，支持固定步长的示例使用 1/60 秒。进程串行启动，性能轮顺序为修改前、前、后、后、前、后。

温控按两张卡的较高值决定是否启动，起跑上限 52°C，每约 75 ms 读取两张卡的 NVML 核心温度，60°C 停止当前子进程。性能轮记录到的最高温度（RTX 2080 / GTX 1080）为修改前 58 / 53°C，修改后 58 / 53°C。

present 间隔包含 CPU 调度、驱动、GPU 和呈现队列。没有锁频或清空驱动着色器缓存。单轮窗口较短，三轮范围重叠时，只能说明本机采样的差异。计时层的 draw 计数和温度轨迹见原始数据。

复测时按进程退出和实际渲染／呈现显卡筛选。保存在原始包但未计入表格的记录为修改前 ssr 第 3 次（渲染或呈现显卡与主测试不一致）、修改后 disney_pbr 第 3 次（timeout）。

## 验证与边界

含性能复测、窗口切换、图像回读及同步验证在内，全程记录的最高核心温度为 RTX 2080 **60°C**、GTX 1080 **54°C**。触发 60°C 停止条件的运行有 2 次，已从性能均值中剔除。

10 项核心及热更新 CTest 通过。legacy CPU 与 GPU 回归用例通过，GPU 用例另在 Vulkan SDK 1.4.350.0 的 Khronos 同步验证层运行。GPU 用例验证了实际像素、计算生成的指令和拷贝回读。

28 个示例另外各运行了一次。启用 Khronos 核心和同步验证后，27 个创建 Vulkan 实例的模式生成了空的验证错误日志；纯编译模式也正常退出。该轮的耗时未混入性能表。

另外实测了双卡显示。GTX 1080 完成 24 帧呈现，期间交替传入 32×32 和 64×64 源图像，交换链从 384×256 调整到 400×300，随后切换到第二个 320×240 窗口。检查每次 displayFrame 调用都成功，验证错误日志为空。

设备选择按设备类型排序。两张卡都是独立显卡，系统枚举顺序变化时，实际渲染卡也可能变化。完整测试按每次创建交换链的设备名筛选。

通用 GPU 图像分配的最终销毁仍然会等待设备空闲，通用 buffer 释放仍可能等待多个队列。当前 API 允许把裸 bindless 索引写入着色器数据，只有调用方掌握其最后一次使用。大量临时图像的创建与销毁仍可能造成停顿，本组帧时未单独量化该成本。离线 shader 缓存开启的构建和其他厂商显卡不在本次数据中。

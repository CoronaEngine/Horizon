# 0001：Core 日志策略与兼容边界

> 状态：已采用
>
> 范围：Core 日志设施及旧日志接口兼容层

## 背景

Core 是可被不同应用复用的基础库。日志文件保留方式、进程信号处理和控制台设置
属于应用的运行策略，不宜由基础库隐式决定；旧日志接口的兼容需求也需要与这些
策略分开处理。

## 决策

日志对进程环境的影响应由应用决定。保留旧调用方式的兼容性，不应成为基础库
重新接管文件保留、信号处理或控制台策略的理由。

## 取舍与影响

兼容接口与后端依赖隔离存在取舍：保留暴露后端类型的旧接口，就不能同时要求后端
完全成为私有实现依赖。后续收敛后端依赖时，需要把调用方的接口迁移纳入设计。

模块职责见 [架构概览](../overview.md)。
